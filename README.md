# Ball vs Ball

เกมลูกบอลสู้กัน 2D — บอล 4 ตัว สกิลต่างกัน เด้งเองตามฟิสิกส์ในกรงสี่เหลี่ยม

- **ARCHER ธนู** — ยิงลูกธนู (7 ดาเมจ, คูลดาวน์ 1.6 วิ)
- **BOMBER ระเบิด** — โยนระเบิดวงกว้าง (15 ดาเมจ, คูลดาวน์ 3.2 วิ)
- **BLADE ใบมีด** — ใบมีดหมุน 3 วิ ปัดธนูได้ (5 ต่อครั้ง, คูลดาวน์ 4.5 วิ)
- **VOLT สายฟ้า** — พุ่งชน (12 ดาเมจ, คูลดาวน์ 2.6 วิ)

ไฟล์เดียว `index.html` ไม่ต้องติดตั้งอะไร เปิดผ่าน GitHub Pages ได้เลย
